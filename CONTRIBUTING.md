# Contributing to Awesome MCP Apps

Thank you for your interest in contributing to Awesome MCP Apps! This guide will help you contribute effectively.

## What to Contribute

We welcome contributions in the following areas:

### 1. New MCP Apps

Add MCP Apps to the appropriate category in README.md. Apps should:
- Provide actual interactive UI (not just text-based MCP tools)
- Use the `@modelcontextprotocol/ext-apps` SDK or follow the MCP Apps specification
- Have a public repository or accessible demo
- Be functional and maintained

### 2. Resources

- Tutorials and guides about building MCP Apps
- Blog posts and articles
- Videos and presentations
- Tools and libraries for MCP App development

### 3. Documentation Improvements

- Fix typos or grammar
- Clarify existing content
- Add examples or use cases
- Update outdated information

## How to Contribute

### Adding a New MCP App

1. Fork this repository
2. Create a new branch (`git checkout -b add-app-name`)
3. Add your MCP App in the appropriate section of README.md
4. Follow the format below:
   ```markdown
   - [App Name](link-to-repo-or-website) - Brief description of what the app does. Key features: feature1, feature2.
   ```
5. Ensure the link works and points to a valid resource
6. Commit your changes (`git commit -m 'Add: App Name'`)
7. Push to your branch (`git push origin add-app-name`)
8. Open a Pull Request

### Adding Resources

Follow the same process as adding apps, but add to the appropriate resource section:
- **Official Resources** - Only official MCP documentation (requires approval)
- **Development Tools** - SDKs, frameworks, testing tools
- **Tutorials & Guides** - Educational content
- **Use Cases** - Real-world examples and case studies

## Submission Guidelines

### Quality Standards

All submissions should meet these criteria:

#### For MCP Apps
- ✅ Uses the official MCP Apps specification
- ✅ Provides interactive UI (not just text responses)
- ✅ Includes a README with setup instructions
- ✅ Is actively maintained or clearly marked as archived
- ✅ Has a clear license
- ✅ Includes screenshots or demo (preferred)

#### For Resources
- ✅ Content is accurate and up-to-date
- ✅ Well-written and easy to understand
- ✅ Adds value to the community
- ✅ Not promotional or spam

### Formatting

- Use consistent markdown formatting
- Keep descriptions concise (1-2 sentences)
- Use proper capitalization and punctuation
- Check for spelling and grammar
- Maintain alphabetical order within categories

### Example Entry

Good example:
```markdown
- [Interactive Dashboard](https://github.com/user/dashboard-app) - Real-time analytics dashboard with filtering and drill-down capabilities. Built with React and MCP Apps SDK.
```

Bad example:
```markdown
- dashboard app - cool app check it out!!!
```

## Categories

Add your MCP App to the most appropriate category:

- **Data Visualization** - Charts, graphs, dashboards
- **Productivity Tools** - Task management, notes, calendars
- **Developer Tools** - Code editors, debugging, testing
- **Entertainment** - Games, media players, creative tools
- **Other** - Anything else

If you think a new category is needed, propose it in your PR.

## Review Process

1. A maintainer will review your PR within 1-2 weeks
2. They may request changes or improvements
3. Once approved, your contribution will be merged
4. Your name will be added to the contributors list

## Code of Conduct

### Our Standards

- Be respectful and inclusive
- Accept constructive criticism gracefully
- Focus on what's best for the community
- Show empathy towards others

### Unacceptable Behavior

- Harassment or discriminatory language
- Trolling or insulting comments
- Spam or promotional content
- Publishing others' private information

## Questions?

If you have questions about contributing:
- Open an issue for discussion
- Check existing issues and PRs for similar topics
- Review the [official MCP Apps documentation](https://modelcontextprotocol.io/docs/extensions/apps)
